# Windows 桌面壁纸

当前客户端为 Tauri + 系统 WebView2。壁纸挂在桌面图标及普通应用后方，无边框、鼠标穿透、不抢焦点；面板关闭后仍继续播放。每次启动默认静音，音量不跨进程恢复。完整房间视频是普通不透明视频，不冒充抠像人物。

## 多屏与控制

每台显示器有独立的原生窗口、播放器、主题、画质和随机路径。按稳定显示器 ID 保存到用户库的 `displays.json`。面板的显示器下拉选择操作目标；托盘菜单作用于全部已连接显示器。托盘双击打开面板，右键显示菜单，单击不弹菜单。

默认 cover 等比铺满并裁剪，也可切换 contain 保留完整画面并留边；不拉伸人物。面板内预览保持完整画面。切换已下载规格只改变选择，点击「设为壁纸」才会应用。菜单分别显示当前选择与桌面使用中；主题、画质均与选定屏幕的有效播放器匹配时显示「当前壁纸」。

预览播放/暂停和音量只控制面板内视频。设为壁纸旁的菜单控制当前屏幕的桌面播放器。停止销毁播放器但保留上次选择和托盘；继续重新加载上次壁纸。关闭面板不停止壁纸；没有设置系统开机自启动。

## 宿主与接片

实现位于 `experiments/tauri-client/src-tauri/src/desktop.rs` 与 `displays.rs`。经典桌面结构使用 wallpaper 插件；Windows 11 raised desktop 识别实际 Progman/图标窗口关系，挂在图标后方并启用合成。窗口按显示器物理像素定位，补偿非客户区，使用 `SetWindowRgn` 将可见范围限制在屏幕内，避免混合 DPI 双屏交界出现边框。不能只凭父窗口非零或解码帧数增长判断壁纸已经可见。

场景包沿明确后继表随机起播、接片；单视频普通循环。片尾遗漏 requestVideoFrameCallback 时，先检查 `new VideoFrame(video)` 的原始解码 PTS。只有它精确落在批准尾帧才提交边界，随后立即关闭快照；不覆盖 timestamp，也不用 currentTime 冒充解码证据。否则仍走受限重解码。避免已解码到结尾却重载 4K 引发误停。

## 验证范围

已验证的本机组合为 Windows 11、3840×2160 / 200% 主屏和 2560×1440 / 100% 副屏，用户确认视频可见、交界窄边消失。4K24 与 1080P60 双屏 180 秒共 29 次接片无播放器停播，但有少量掉帧，不代表长期零卡顿。

自动检测失效宿主和显示器变化并尝试重新挂载。物理热插拔、Explorer 重启、睡眠唤醒、虚拟桌面切换和其他 Windows 版本尚未完整验收。WorkerW/raised desktop 属于 Explorer 实现细节，并非微软承诺稳定的动态壁纸 API。

当前公开主题规格为 720P24、1080P24、1080P60，4K24 仅本机可用。见[发布说明](RELEASE_NOTES.md)。

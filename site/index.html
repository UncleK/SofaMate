A FEW THINGS TO KNOW.

开始陪伴之前。

关于 SofaMate，你可能想知道的事。

SofaMate 是什么？

SofaMate 是 Windows 桌面视频陪伴软件。把喜欢的人物视频设为动态壁纸，让工作、学习和独处的日常多一份陪伴。你可以选择女性、男性或其他喜欢的角色；视频内容由你导入或从分享市场下载。

怎样开始使用？

下载并解压 Windows 版，打开 SofaMate，导入一个喜欢的 MP4 视频，再点击“设为壁纸”。公开下载包不附带演示主题，你可以使用自己的视频，也可以浏览分享市场。

它能聊天或实时回应我吗？

当前版本通过视频呈现桌面陪伴，不提供 AI 聊天、语音对话或实时互动。窗口里的预览和桌面播放各自控制，暂停、继续和停止都由你决定。

需要注册吗？账号和 Aveniqa 通用吗？

本机导入、播放、浏览市场和下载无需注册，发布与管理作品需要登录。当前支持邮箱验证码、GitHub 和 Google；SofaMate 与 Aveniqa 共用统一账号，无需重复注册。

免费吗？客户端有多大？

v0.1.0 公开测试版可免费下载和使用，Windows ZIP 下载包约 1.89 MiB，不含视频。使用系统 WebView2 Runtime，视频占用空间另计；点击停止会关闭桌面播放器并释放其播放资源，托盘仍保留。

支持哪些系统、视频和语言？

当前支持 Windows 10 / 11 x64、单主屏，以及 H.264 / AAC 编码的 MP4，单视频最大 1 GiB。客户端支持简体中文、英语和日语。九宫格预览在本机生成，导入不会自动上传；主动分享才会上传。
